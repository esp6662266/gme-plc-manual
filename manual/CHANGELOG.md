# 문서 변경 이력

## 1.0 2026년 10월 7일

- HMI 화면과 PLC 실행 구조, 장치별 제어, 자동 순서, PV01 진단을 작성했다.
- PV01 네 가지 개선안과 명령당 두 번 실패 처리의 조건과 시험 범위를 정리했다.
- Historical Alarms의 SQL 저장 증거와 태그 이력 경로를 구분했다.
- Main Network 14와 15의 유지보수 제한 로직 및 실제 재발 기록을 정리했다.
- 원본 백업 위치, 복구 범위, 주소 호환 계층과 단계적 개선 절차를 작성했다.
- 10월 7일 유선 링크 단절과 PLC 통신 장애의 현재 증거를 추가했다.
- 시스템·실행·PV01·유지보수·개선 구성도와 탐색용 CSV를 작성했다.
- Markdown, HTML, PDF와 홈페이지를 파일로 제공한다.

## 1.1 2026년 10월 7일

- 홈페이지 운영 방식을 GitHub와 Netlify 연결로 변경했다.
- 서버 자료실을 Netlify Identity와 Blobs로 구성하고, 업로드를 파일당 최대 4MB로 제한했다.
- 실제 게시 및 이메일 발송 결과는 배포 상태 안내에 별도로 기록한다.
