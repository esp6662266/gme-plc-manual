- 22개 장의 매뉴얼과 검색 홈페이지, 31쪽 PDF, Markdown, 그림, 참조 CSV를 준비했다.
- Netlify 계정 로그인을 확인했다.
- 서버 자료실 코드와 계정별 파일·개정 이력 저장 기능을 준비했다.
- 서버 자료실의 로그인 요구, 계정 격리, 버전 보존, 개정 충돌과 저장 실패 처리를 검사했다.
