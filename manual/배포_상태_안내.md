# GME 매뉴얼 홈페이지 게시 상태

확인일: 2026년 10월 7일 · 문서 버전 1.1

## 게시 주소

- 홈페이지: https://gme-plc-manual.netlify.app/
- 공개 GitHub 저장소: https://github.com/esp6662266/gme-plc-manual
- 서버 자료실: https://gme-plc-manual.netlify.app/library/

## 완료한 작업

- 22개 장의 한국어 매뉴얼, 검색 홈페이지, 31쪽 PDF, Markdown, 그림 5종 및 참조 CSV 5종을 게시했다.
- 공개 저장소에 홈페이지 소스와 문서 38개 파일을 등록하고 파일 해시의 일치를 확인했다.
- Netlify 프로젝트를 위 저장소의 main 브랜치에 연결했다. 빌드 명령은 npm run build, 게시 폴더는 dist, 함수 폴더는 netlify/functions다.
- 첫 GitHub 자동 배포가 성공했다. 소스 커밋은 5cfc611317887a5888e103cceb2d10b96995532c, 배포 ID는 6ac5d79fd222b1309c3fd691이다.
- 실제 홈페이지 접속과 PV01 검색 결과 2개 장을 확인했다. PDF·Markdown·블록 CSV·시스템 구성도는 HTTP 200이며 로컬 파일과 바이트가 일치했다.
- Netlify Identity를 활성화했다. 이메일 가입과 이메일 확인이 적용되어 있으며, 자동 이메일 확인은 꺼져 있다.
- 서버 자료실 함수 1개를 배포했다. 로그인하지 않은 /api/documents 요청은 HTTP 401과 '자료실 로그인이 필요합니다.'를 반환한다. 자료실 화면에 로그인·계정 등록·비밀번호 찾기가 표시된다.
- 자료실 서비스의 자동 시험 4개가 통과했다. 로그인 요구, 계정 격리, 이전 버전 보존, 동시 개정 충돌, 파일 검증과 저장 실패 처리를 포함한다.
- 요청한 세 수신처에 홈페이지와 GitHub 주소 안내 이메일을 발송했다. Gmail 보낸편지함의 SENT 기록과 세 수신처를 확인했다. 각 수신처의 받은편지함 도착 여부는 확인 범위에 포함되지 않는다.

## 자료실 사용과 남은 확인

매뉴얼은 로그인 없이 읽을 수 있다. 자료를 저장하려면 홈페이지의 서버 자료실에서 계정을 등록하고 이메일 확인을 완료한다. GitHub·Netlify 관리 계정과 별개의 자료실 계정이다.

파일당 업로드 한도는 4MB이며, 계정별 자료와 개정 이력을 Netlify Blobs에 보관하도록 구현했다. 실제 자료실 계정으로 로그인한 뒤 업로드·조회·다운로드하고 재배포 후 보존 여부를 확인하는 운영 시험은 아직 수행하지 않았다. 사용자 비밀번호를 대신 만들거나 입력하지 않았다.

홈페이지 빌드의 게시 대상은 dist 폴더에 생성되는 기술 문서와 자료실 화면이다. 실제 PLC를 제어하거나 운전 상태를 실시간 표시하지 않는다. 현재 PLC와 보관 프로젝트의 전체 일치 여부는 매뉴얼의 추가 확인 과제로 남아 있다.
