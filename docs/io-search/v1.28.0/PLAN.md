# 부품·선번 연결 추적 구현 계획

> **Execution:** 현재 사용자 승인과 저장소 지침을 따라 구현·검증한다.

**Goal:** 여섯 검색 결과에서 보존 도면상 접점·코일·선번·단자 연결을 읽고 각 위치를 연다.
**Architecture:** 기존 6개 reference 레코드에 수동 대조한 trace를 추가한다. 별도 네트워크 요청 없이 기본 색인에 포함하고, 순차 경로와 병렬 분기를 구분한다. 노드는 자체 PDF 페이지와 인쇄된 검색어로 위치창을 연다.
**Tech Stack:** 기존 JavaScript/HTML/CSS, JSON, Node 검사.
**Spec:** 직전 대화의 승인된 제안(14KA6·14KA8·14KA10·8.9·8.10·13.6)과 원본 Electrical_Rev2.pdf FG8/9/13/14/15/27/30/42.

- [x] `io-search-reference-notes.json`: 원본 해시·FG/PDF·접점 단자·선번·코일 귀환·병렬 분기와 미확인을 기록한다. 13KA1:24를 전압으로 해석하지 않고 STO 접점6→5/2→1/4→3 방향을 보존한다.
- [x] `io-connections.js/css`: 기존 남색(#142c40)/청록(#087f78)/밝은 회색(#f5f8fa)/흰색, 시스템 한글 글꼴, 왼쪽 정렬을 유지한다. 연결 순서는 세로 목록과 연결선으로, 코일 병렬은 분기 목록으로 표시한다. 경로 선택·도면 위치·관련 번호 전체 검색을 제공한다. 모바일에서 가로 넘침이 없어야 한다.
- [x] `io-search.js`와 뷰어: 노드별 검색어·필요한 태그 위치를 사용한다. 관련 검색은 필터를 초기화하고 뒤로가기 가능한 링크로 제공한다. 추가 본문 도착으로 버튼이 교체돼도 위치창 닫기 초점이 복귀한다.
- [x] Node 검사로 구조·번호/전압·방향·순차/병렬·노드별 실제 좌표·HTML escaping·링크/필터를 확인한다. 브라우저에서 여섯 검색·경로 전환·위치·관련 검색/뒤로가기·휴대폰·키보드를 확인한다.
- [x] v1.28.0 버전/생성기/manifest·원본/중지 해시·필수14+2·ZIP CRC/전체내용·build/CSP를 확인하고 GitHub/Netlify 실제 게시까지 검증한다.

검토 초점: 선번과 단자대 번호 혼동, 13KA1:24와24V 혼동, 병렬 코일의 직렬 오표시, 다른 접점 방향으로 임의 정렬, OCR 후보를 확인된 연결로 승격, 로딩 중 초점 소실. 원본/OCR 추출·운영기록/저장 키·시뮬레이터와 보류 도면상충은 변경하지 않는다.
