3. 원본에서 확인한 핵심 동작

FN06은 RD01 운전 응답과 연동되며 원본 고장 이름이 다른 장치 명칭으로 나타납니다.

드럼 정지 후 보조 팬 요청이 사라짐Inputs.RD01 run과 UNDER TESTING, Flag.M_FN_06을 확인합니다.1955는 RD01 응답 없음 AND NOT UNDER TESTING을 요청 리셋 경로로 사용합니다.설비 간 정지 정책과 실제 RD01 응답 전달을 확인합니다.
FN06 고장 표시 이름이 다름Allarm.MBVA01_FAULT의 Set·Reset과 FN06 요청 리셋을 연결해 봅니다.1802의 감시 설정은 2초이며 1955는 MBVA01_FAULT를 사용합니다.태그명만 보고 다른 고장으로 치환하지 않습니다. 알람 이름·HMI 문구·실물 장치의 관계를 확인합니다.

5. 복구와 재기동 확인

  1. 원인 입력과 실제 장치 이상이 복구됐는지 별도로 확인합니다.
  2. 래치 해제 조건을 원본에서 확인하고 Reset 펄스·유지 상태를 구분해 기록합니다.
  3. 운전 요청 Flag, 단계 기억, 타이머·재시도 상태가 남는지 확인합니다.
  4. 정지 상태에서 허가를 확인한 뒤 승인된 새 기동 절차로 응답·출력·알람을 관찰합니다.
  5. 정상·고장·복구·전원 재시작을 분리해 결과를 남깁니다. 보존한 과거 가상 시험 결과와 실제 수리 완료를 구분합니다. 추가 가상 시험은 중지 상태입니다.

6. 개선 검토와 남은 확인

  • TIA 호출 조건·주기·중복 쓰기 순서와 전원 재시작 동작 확인
  • 현재 PLC 프로그램·현장 설치·단자·정상 극성 및 실제 설정값 대조
  • 시험 기대 결과 확정과 실행 증거 수집
  • 상태 전환 순서 또는 단일 동작·수동 장치 여부 미확정
