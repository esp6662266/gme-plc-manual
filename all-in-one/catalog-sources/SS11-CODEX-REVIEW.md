# SS11 · 현재 보존 원본 검토

## 1. 설비·자료 기준

SS11(이송 장치 감시 스위치)는 실제 대장에서 센서·계측 구성품으로 분류합니다. 담당 부모는 MC05입니다.

트립와이어·회전 또는 토크 감시의 실제 장치 종류와 접점 방향을 확인한다.

MC05_torque Monitor 선언은 남아 있지만 복원426개 LAD에서 같은 이름의 원시 핀이나 처리 MC05 torque 핀은 찾지 못했습니다. OEM 전체 SPARE와 시공 케이블명 MC04/끝점 MC05 상충은 별도 관찰 항목입니다.

Dots 원초안은 abcf31c/v1.12.0 당시 연구 자료이며 원문 바이트를 보존했습니다. 아래는 현재 원본과 독립 대조한 검토본입니다.

SS11 대장에는 입력·출력·내부 신호 1행과 HMI 설정 0행이 연결됩니다.

## 4. 전기 전달 경로

선택한 OEM 원본 위치는 FG26/PDF27입니다. 도면 FG와 PDF 페이지를 별도 필드로 유지합니다.

시공 PDF 태그 등장 페이지 3, 5, 34, 59는 실제 조사 범위입니다. 등장만으로 케이블 끝점·부품 소유·현장 접속을 확정하지 않습니다.

시공 표지 FOR APPROVAL과 빈 APPROVED 상태를 승인 시공·현재 실물 배선 완료로 해석하지 않습니다.

P&ID에서 이 고유 ID의 독립된 정확한 태그는 확인하지 못했습니다. 대장 pid 표시는 전용 I/O·회로 근거가 아닙니다.

- OEM FG26/PDF27은 METALLIC CONVEYOR MC-05와 SS-11 LIMIT SWITCH TORQUE CONTROL E6.6을 표시합니다. SPARE 점선 박스는 MC-05 모터 회로와 SS-11을 함께 둘러쌉니다.
- 시공 PDF59 행9_8의 케이블명은 =EXI+MC04-SS11A이지만 FROM은 MC-05/EXI1TB2, TO는 MC-05/SS-11입니다. 이름 MC04와 끝점 MC05의 상충을 유지합니다. 원문 규격은 DC·CVV·2C·1.0·SPARE0입니다.

| 시공 PDF·행 | 원문 케이블 | FROM | TO | 전류형식·선종·코어·굵기 | 검토 |
| --- | --- | --- | --- | --- | --- |
| 59 / 9_8 | =EXI+MC04-SS11A | MC-05 / EXI1TB2 | MC-05 / SS-11 | DC / CVV / 2C / 1.0 | 식별자의 MC04와 TO의 MC05가 다릅니다. C07 대기. MC04·MC05·SS11을 병합하지 않습니다. |
