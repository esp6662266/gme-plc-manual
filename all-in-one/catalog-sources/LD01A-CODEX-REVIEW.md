# LD01A · 현재 보존 원본 검토

## 1. 설비·자료 기준

LD01A(석회 사일로 진동기)는 실제 대장에서 보조 구동장치으로 분류합니다. 담당 부모는 LD01입니다.

LD01의 간헐 운전/정지 타이머와 현장 요청에 연결되는 진동기.

OEM FG56/PDF57 SILO VIBRATOR LD-01A는 M33·56QM1·56KM1·56QS1, A3.7 명령과 E4.7 피드백을 표시합니다. 도면의 모터 표기0.18kW·0.55A와 56QM1의2.2-3.2A 범위는 별도 표기이며 현재 보호 설정으로 선택하지 않습니다.

1085는 보존된 과거 Simulation 블록의 정적 참조이며 실제 입력 전달 근거가 아닙니다. 이를 실행하지 않았습니다. 실제 간헐 주기나 기계 진동을 임의로 채우지 않습니다.

Dots 원초안은 abcf31c/v1.12.0 당시 연구 자료이며 원문 바이트를 보존했습니다. 아래는 현재 원본과 독립 대조한 검토본입니다.

## 4. 전기 전달 경로

선택한 OEM 원본 위치는 FG56/PDF57입니다. 도면 FG와 PDF 페이지를 별도 필드로 유지합니다.

시공 PDF 태그 등장 페이지 36, 60는 실제 조사 범위입니다. 등장만으로 케이블 끝점·부품 소유·현장 접속을 확정하지 않습니다.

시공 표지 FOR APPROVAL과 빈 APPROVED 상태를 승인 시공·현재 실물 배선 완료로 해석하지 않습니다.

- OEM FG56/PDF57 SILO VIBRATOR LD-01A는 M33·56QM1·56KM1·56QS1, A3.7 명령과 E4.7 피드백을 표시합니다. 도면의 모터 표기0.18kW·0.55A와 56QM1의2.2-3.2A 범위는 별도 표기이며 현재 보호 설정으로 선택하지 않습니다.
