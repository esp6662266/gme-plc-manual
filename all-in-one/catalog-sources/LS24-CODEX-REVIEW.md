# LS24 · 현재 보존 원본 검토

## 1. 설비·자료 기준

LS24(밸브 위치 리미트 스위치)는 실제 대장에서 하위 구성품으로 분류합니다. 담당 부모는 MV01입니다.

개방/폐쇄 위치 센서. 번호·방향·단자·PLC 입력을 상위 장치와 대조한다.

OEM FG45/PDF46의 LS-24 원문 기능은 VALVE CLOSING(밸브 닫힘)입니다. 퓨즈를 거친24V 경로는 X1:114/115에서 E8.2 입력으로 이어집니다.

LS24는 MV01의 끝위치 구성품입니다. 인용한 원시 입력은 구성품 근거로 다루지만 부모 액추에이터 출력·PID·알람을 새 독립 기능으로 복제하지 않습니다.

Dots 원초안은 abcf31c/v1.12.0 당시 연구 자료이며 원문 바이트를 보존했습니다. 아래는 현재 원본과 독립 대조한 검토본입니다.
