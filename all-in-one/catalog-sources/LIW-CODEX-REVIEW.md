# LIW · 현재 보존 원본 검토

## 1. 설비·자료 기준

LIW(외부 LIW 피더)는 실제 대장에서 외부 연동 설비으로 분류합니다. 별도 부모 ID는 배정되어 있지 않습니다.

고객 피더 시스템 원격 시작과 속도 설정. BWF 계통 및 배출 분기 상태와 교차 검토한다.

외부 인터페이스 범위입니다. 명령·피드백·상태 원본 참조만으로 고객 모터의 배선·내부 인터록·현재 실물 동일성을 확정하지 않습니다.

외부 인터페이스 범위입니다. 명령·피드백·상태 원본 참조만으로 고객 모터의 배선·내부 인터록·현재 실물 동일성을 확정하지 않습니다.

Dots 원초안은 abcf31c/v1.12.0 당시 연구 자료이며 원문 바이트를 보존했습니다. 아래는 현재 원본과 독립 대조한 검토본입니다.

## 2. I/O·HMI

LIW 대장에는 입력·출력·내부 신호 3행과 HMI 설정 0행이 연결됩니다.

- liw systemautoreader — %i14.1 / bool / 원본 문서529; 원본 XML의 SAD/SSD·자료형 및 백업 주소 대응 확인; 같은 이름 LAD 핀 1곳. 원문 설명: e 15.0 liw systemautoreader
- start liw feeder — %q6.1 / bool / 원본 문서679; 원본 XML의 SAD/SSD·자료형 및 백업 주소 대응 확인; 같은 이름 LAD 핀 3곳. 원문 설명: a 61.1 liw feederremote start
- liw_sp_speed — %qw302 / word / 원본 문서1346; 원본 XML의 SAD/SSD·자료형 및 백업 주소 대응 확인; 같은 이름 LAD 핀 1곳. 원문 설명: speed set liw system(client machine)(4-20ma)

## 4. 전기 전달 경로

선택한 OEM 원본 위치는 FG84/PDF85, FG85/PDF86, FG90/PDF91입니다. 도면 FG와 PDF 페이지를 별도 필드로 유지합니다.

P&ID에서 이 고유 ID의 독립된 정확한 태그는 확인하지 못했습니다. 대장 pid 표시는 전용 I/O·회로 근거가 아닙니다.

- OEM FG84/PDF85 원격 기동 릴레이84KA2는 A6.1 출력과 주황색 접점 단자 X1:234/235를 표시합니다. FG85/PDF86의 LIW4-20mA 속도 설정은 PAW302 및 X1:249/250/251입니다.
- liw systemautoreader %i14.1와 OEM 인터페이스 단자 X1:312/313를 비교합니다. 고객 제어반 끝점 및 현재 접속은 별도 확인입니다.

| 원문 신호 | 백업 주소 | OEM 원문 끝점 | 현재 고객/현장 경계 |
| --- | --- | --- | --- |
| liw systemautoreader | %i14.1 | X1:312/313 | 인터페이스 단자 근거; 고객 제어반 내부/현재 배선 미확정 |

## 5. 알람·복구

1973의15분 시간 경로는 LIW 시작·정지 요청 경로입니다. 이를 LIW 전용 고장 알람으로 만들지 않습니다.

1973의 START LIW FEEDER Set은 BWF01 또는 BWF02 RUN 및 PV-03 GATE EV를 필요로 합니다. 두 SdCoil 시간 원문은 S5T#15M이며15초가 아닙니다. Tag_127과 Tag_128을 다른 시간 경로로 유지합니다.

외부 인터페이스 범위입니다. 명령·피드백·상태 원본 참조만으로 고객 모터의 배선·내부 인터록·현재 실물 동일성을 확정하지 않습니다.

## 6. 증상별 관찰

LIW의 원인은 아래 관찰을 실제로 수집한 뒤 원본과 비교합니다. 빈 관찰 양식을 현재 값이나 복구 완료 증거로 채우지 않습니다.

- 외부 LIW 피더 인터페이스의 실제 값·시각·주소(liw systemautoreader %i14.1, start liw feeder %q6.1, liw_sp_speed %qw302)와 OEM 단자 및 고객 제어반 끝점의 비교
- 고객 인터페이스·운전시간 원본 참조를 대조하되 고객 안전·기동 내부 회로를 추정하지 않음
- 현재 설치·명판·호출 주체·명령 계약을 독립 확인
