# LS34 · 현재 보존 원본 검토

## 1. 설비·자료 기준

LS34(밸브 위치 리미트 스위치)는 실제 대장에서 하위 구성품으로 분류합니다. 담당 부모는 MV06입니다.

개방/폐쇄 위치 센서. 번호·방향·단자·PLC 입력을 상위 장치와 대조한다.

P&ID MV06 위치 접점은 LS-34/LS-35이며 시공 PDF58 행8_19/8_20도 같은 번호입니다.

LS34에는 직접 I/O를 배정하지 않았습니다. I6.7을 이 항목에 중복 배정하거나 LS34와 LS40을 새 식별 근거 없이 병합하지 않습니다.

Dots 원초안은 abcf31c/v1.12.0 당시 연구 자료이며 원문 바이트를 보존했습니다. 아래는 현재 원본과 독립 대조한 검토본입니다.

## 2. I/O·HMI

LS34 대장에는 입력·출력·내부 신호 0행과 HMI 설정 0행이 연결됩니다.

LS34 전용 주소는 식별하지 못했습니다. LS34에는 직접 I/O를 배정하지 않았습니다. I6.7을 이 항목에 중복 배정하거나 LS34와 LS40을 새 식별 근거 없이 병합하지 않습니다.

## 3. 제어 구조

## 4. 전기 전달 경로

선택한 OEM 원본 위치는 FG30/PDF31, FG31/PDF32, FG32/PDF33, FG33/PDF34입니다. 도면 FG와 PDF 페이지를 별도 필드로 유지합니다.

시공 PDF 태그 등장 페이지 3, 5, 33, 58는 실제 조사 범위입니다. 등장만으로 케이블 끝점·부품 소유·현장 접속을 확정하지 않습니다.

시공 표지 FOR APPROVAL과 빈 APPROVED 상태를 승인 시공·현재 실물 배선 완료로 해석하지 않습니다.
