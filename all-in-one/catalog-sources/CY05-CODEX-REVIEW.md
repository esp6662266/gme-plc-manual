# CY05 · 현재 보존 원본 검토

## 1. 설비·자료 기준

CY05(사이클론)는 실제 대장에서 수동 분리 본체으로 분류합니다. 별도 부모 ID는 배정되어 있지 않습니다.

P&ID의 분진 분리 본체. 배출 로터리 밸브 또는 SC01 경로와 연결해 점검한다.

P&ID 아래쪽 세 사이클론 중 오른쪽 본체입니다. 하부 집진 경로는 SC-01 스크루 컨베이어를 거쳐 VR-03으로 이어집니다.

전용 사이클론 I/O·HMI·LAD·알람·타이머는 대장 제어 행, 복원426개 네트워크 및 원본 선언의 정확한 태그 조사에서 식별하지 못했습니다. 기계 관찰을 새 알람으로 만들지 않습니다.
