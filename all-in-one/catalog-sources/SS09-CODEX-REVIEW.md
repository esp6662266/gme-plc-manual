# SS09 · 현재 보존 원본 검토

## 1. 설비·자료 기준

SS09(이송 장치 감시 스위치)는 실제 대장에서 센서·계측 구성품으로 분류합니다. 담당 부모는 MC03입니다.

트립와이어·회전 또는 토크 감시의 실제 장치 종류와 접점 방향을 확인한다.

MC03_torque는 원본 XML의 Monitor 선언으로 확인되지만 복원 LAD에서 같은 이름의 원시 핀을 찾지 못했습니다. Inputs.MC03 torque와 원시 전달을 확정하지 않습니다. MC03 알람을 독립 스위치 출력·알람으로 복제하지 않습니다.

Dots 원초안은 abcf31c/v1.12.0 당시 연구 자료이며 원문 바이트를 보존했습니다. 아래는 현재 원본과 독립 대조한 검토본입니다.

## 4. 전기 전달 경로

선택한 OEM 원본 위치는 FG23/PDF24입니다. 도면 FG와 PDF 페이지를 별도 필드로 유지합니다.

P&ID에서 이 고유 ID의 독립된 정확한 태그는 확인하지 못했습니다. 대장 pid 표시는 전용 I/O·회로 근거가 아닙니다.

- OEM FG23/PDF24의 실제 도면 제목은 SPARE이며 LIMIT SWITCH TORQUE CONTROL SS-09 E6.4를 표시합니다. X1:52/53과2A 퓨즈를 대조합니다.
