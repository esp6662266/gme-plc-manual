# SS01 · 현재 보존 원본 검토

## 1. 설비·자료 기준

SS01(이송 장치 감시 스위치)는 실제 대장에서 센서·계측 구성품으로 분류합니다. 담당 부모는 BC01입니다.

트립와이어·회전 또는 토크 감시의 실제 장치 종류와 접점 방향을 확인한다.

BC01 처리 트립와이어 알람은 부모 관련 근거입니다. BC01_tripwire/prox라는 정확한 이름의 원시 입력이 가공 Inputs로 전달되는 직접 경로는 복원 원본에서 찾지 못했습니다. SS-01 트립와이어와 예비 SSL-01 회전감시를 하나의 장치로 합치지 않습니다.

Dots 원초안은 abcf31c/v1.12.0 당시 연구 자료이며 원문 바이트를 보존했습니다. 아래는 현재 원본과 독립 대조한 검토본입니다.

## 2. I/O·HMI

BC01 처리 트립와이어 알람은 부모 관련 근거입니다. BC01_tripwire/prox라는 정확한 이름의 원시 입력이 가공 Inputs로 전달되는 직접 경로는 복원 원본에서 찾지 못했습니다. SS-01 트립와이어와 예비 SSL-01 회전감시를 하나의 장치로 합치지 않습니다.

## 4. 전기 전달 경로

선택한 OEM 원본 위치는 FG18/PDF19, FG19/PDF20입니다. 도면 FG와 PDF 페이지를 별도 필드로 유지합니다.

시공 PDF 태그 등장 페이지 3, 5, 21, 53는 실제 조사 범위입니다. 등장만으로 케이블 끝점·부품 소유·현장 접속을 확정하지 않습니다.

시공 표지 FOR APPROVAL과 빈 APPROVED 상태를 승인 시공·현재 실물 배선 완료로 해석하지 않습니다.

- OEM FG19/PDF20은 SS-01 기동 직렬 접점11-12와 PLC 감시 접점13-14를 별도 회로로 그립니다. 기동 경로는 X1:44/45·XS1/2·18QS1·18QM1·19KA1이며 감시 경로는 X1:46/47에서 E6.2로 이어집니다.
- SSL-01 R.P.M. CONTROL SWITCH는 SPARE 점선 박스 안에 있습니다. X1:48/49에서 E6.3으로 이어집니다. I6.3 검색 색인 및 시공 케이블이 남아 있어도 현재 설치·사용을 확정하지 않습니다.

| 53 / 3_18 | =ENT+BC01-SS01A | BC-01 / ENT1TB1 | BC-01 / SS-01 | DC / CVV / 5G / 1.0 | 기존 FG19의 직렬 허가 접점과 PLC 감시 접점은 별도 회로입니다. |

## 5. 알람·복구

SS01 전용 알람·타이머는 직접 확보된 근거로만 설명합니다. 부모·공통 알람과 기계 관찰을 새 독립 알람으로 만들지 않습니다.

BC01 처리 트립와이어 알람은 부모 관련 근거입니다. BC01_tripwire/prox라는 정확한 이름의 원시 입력이 가공 Inputs로 전달되는 직접 경로는 복원 원본에서 찾지 못했습니다. SS-01 트립와이어와 예비 SSL-01 회전감시를 하나의 장치로 합치지 않습니다.

- BC01 처리 트립와이어 알람은 부모 관련 근거입니다. 원시 입력→Inputs의 미해석 전달과 기동 직렬 접점을 따로 기록합니다.

## 6. 증상별 관찰

SS01의 원인은 아래 관찰을 실제로 수집한 뒤 원본과 비교합니다. 빈 관찰 양식을 현재 값이나 복구 완료 증거로 채우지 않습니다.

- SS-01 기동 직렬 경로 X1:44/45·XS1/2·18QS1·18QM1·19KA1와 감시 경로 X1:46/47→E6.2의 별도 상태
- SSL-01 X1:48/49→E6.3의 SPARE 표기와 실제 설치 여부의 별도 기록
