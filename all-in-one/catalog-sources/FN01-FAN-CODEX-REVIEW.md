# FN01-FAN · 현재 보존 원본 검토

## 1. 설비·자료 기준

FN01-FAN(FN01 모터 냉각팬)는 실제 대장에서 보조 구동장치으로 분류합니다. 담당 부모는 FN01입니다.

FN01 구동부 냉각 보조장치.

OEM FG54/PDF55 냉각팬 전체 회로는 SPARE 박스 안에 있습니다. M29·54QM1·54KM1·54QS1, A3.5 명령과 E4.5 피드백을 표시합니다.

전용 최종 명령·원시 피드백 LAD 경로는 미확보입니다. FN01 주 팬·인버터의 알람·타이머를 냉각팬에 복제하지 않습니다. SPARE·삭제 표기와 현재 설치 여부를 구분합니다.

Dots 원초안은 abcf31c/v1.12.0 당시 연구 자료이며 원문 바이트를 보존했습니다. 아래는 현재 원본과 독립 대조한 검토본입니다.

## 2. I/O·HMI

FN01-FAN 대장에는 입력·출력·내부 신호 2행과 HMI 설정 0행이 연결됩니다.

Star fan FN01 Q3.5와 FN01F_Fbk I4.5는 원본 XML Monitor 선언으로 확인됩니다. 복원 LAD에서 같은 이름의 원시 핀 참조는 찾지 못했습니다.

- fn01f_fbk — %i4.5 / bool / 원본 문서1057; 원본 XML의 SAD/SSD·자료형 및 백업 주소 대응 확인; 같은 이름 LAD 핀 0곳. 원문 설명: feedback cooling fan motor fn-01
- star fan fn01 — %q3.5 / bool / 원본 문서997; 원본 XML의 SAD/SSD·자료형 및 백업 주소 대응 확인; 같은 이름 LAD 핀 0곳. 원문 설명: a 53.5 fn-01 motorcommand cooling fan

## 4. 전기 전달 경로

선택한 OEM 원본 위치는 FG54/PDF55입니다. 도면 FG와 PDF 페이지를 별도 필드로 유지합니다.

P&ID에서 이 고유 ID의 독립된 정확한 태그는 확인하지 못했습니다. 대장 pid 표시는 전용 I/O·회로 근거가 아닙니다.

- OEM FG54/PDF55 냉각팬 전체 회로는 SPARE 박스 안에 있습니다. M29·54QM1·54KM1·54QS1, A3.5 명령과 E4.5 피드백을 표시합니다.

## 5. 알람·복구

FN01-FAN 전용 알람·타이머는 직접 확보된 근거로만 설명합니다. 부모·공통 알람과 기계 관찰을 새 독립 알람으로 만들지 않습니다.

전용 최종 명령·원시 피드백 LAD 경로는 미확보입니다. FN01 주 팬·인버터의 알람·타이머를 냉각팬에 복제하지 않습니다. SPARE·삭제 표기와 현재 설치 여부를 구분합니다.

- FN01 주 팬·인버터 알람·타이머를 냉각팬에 복제하지 않습니다. 선언·SPARE·공통 정지 참조만으로 냉각팬 보호 기능을 확정하지 않습니다.

## 6. 증상별 관찰

FN01-FAN의 원인은 아래 관찰을 실제로 수집한 뒤 원본과 비교합니다. 빈 관찰 양식을 현재 값이나 복구 완료 증거로 채우지 않습니다.

- M29 명판·존재 여부, 54KM1 접점 및 XS45/46 명령 경로
- Q3.5/I4.5 선언과 실제 배선·SPARE/삭제 표기의 비교
- FN_01_FAN_HOUR Reset 및 Flag.M_FN_01_FAN 정지 참조는 관련 근거로만 기록
