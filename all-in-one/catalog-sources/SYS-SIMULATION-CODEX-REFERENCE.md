# SYS-SIMULATION · 보존 원본과 영구중지 참조

## 1. 설비·자료 기준

기존 백업 Simulation 블록의 목록·선언과 영구중지 정책을 설명하는 정적 참조 문서입니다. 시뮬레이터 작성·수정·생성·실행·행동 시험은 하지 않습니다. 현재 CPU 실행·실제 입력 대체·현장 효과는 미확정입니다.

본 ID는 공통 소프트웨어 문서 분류이며 독립 실물이나 새 프로그램이 아닙니다. 현재 129개 2차 대장의 문서 항목이고, 시뮬레이터 실행 재개를 뜻하지 않습니다.

## 4. 전기 전달 경로

이 소프트웨어 참조에 전용 전기 경로를 배정하지 않습니다. 물리 입력·릴레이·인버터·밸브는 원래 설비의 전기/시공 도면 소유입니다. 보존 처리 Inputs 쓰기 후보를 현장 배선 증거로 사용하지 않습니다.

## 5. 알람·복구

시험 비트의 이름이나 보존 Simulation 경로만으로 알람 정상·해제·안전·재기동·복구를 확정하지 않습니다. 전용 장치의 원인·Set/Reset·출력·실제 응답은 해당 장치 문서로 대조합니다.

## 6. 증상별 관찰

- 실물 응답과 문서의 처리 응답이 다름: 기존 관찰 시각·원시 입력·처리 입력·프로젝트 판본 및 실제 설비 명칭 / 해당 설비의 전용 원본과 보존 Simulation 참조를 구분합니다. 이 문서의 목록을 실제 입력 전달 증거로 사용하지 않습니다.
- 시험 비트의 의미 또는 현재 적용 여부가 불명확함: 담당자가 제공한 현재 승인 프로젝트의 호출·교차참조 자료와 판본 / 백업 Memory 선언과 현재 실행을 분리합니다. 비트 전환·가상 시나리오·실행 시험은 하지 않습니다.

## 7. 완료·누락·검증

정적 참조 문서 범위의 완료와 실제 PLC/TIA·현장 검증을 분리합니다.

- 현재 승인 엔지니어링 프로젝트에서 해당 블록의 호출·조건·다른 Writer 및 실제 온라인 상태 대조 필요
- 원시 물리 입력·처리 Inputs·시험 비트는 서로 다른 근거이며 보존 Simulation의 쓰기 후보로 실물 전달을 확정하지 않음
- 개별 설비의 정상 극성·실물·보호 설정·재기동·복구는 별도 담당 자료 필요
- 신규 시뮬레이터 개발·실행 재개 대상에서 영구 제외; 중지5자산 해시 보존
