# LT01 · 현재 보존 원본 검토

## 1. 설비·자료 기준

LT01(석회 사일로 레벨)는 실제 대장에서 센서·계측 구성품으로 분류합니다. 담당 부모는 LD01입니다.

LD01 사일로의 P&ID 레벨 태그. PLC 저레벨 입력과 현장 센서 동일성을 확인한다.

P&ID LT-01과 OEM 이산 저레벨 접점의 현재 실물 동일성 및 정상 극성은 확인 전입니다. 아날로그 환산이나 사일로 백분율을 만들지 않습니다.

Dots 원초안은 abcf31c/v1.12.0 당시 연구 자료이며 원문 바이트를 보존했습니다. 아래는 현재 원본과 독립 대조한 검토본입니다.

## 2. I/O·HMI

LT01 대장에는 입력·출력·내부 신호 1행과 HMI 설정 0행이 연결됩니다.

P&ID의 LT-01은 LD-01 사일로 옆에 있습니다. OEM FG170/PDF171은 아날로그 LT 채널 대신 LOW LEVEL LD-01 접점 회로를 표시합니다.

## 4. 전기 전달 경로

선택한 OEM 원본 위치는 FG170/PDF171입니다. 도면 FG와 PDF 페이지를 별도 필드로 유지합니다.

시공 PDF 태그 등장 페이지 3, 5, 36, 60는 실제 조사 범위입니다. 등장만으로 케이블 끝점·부품 소유·현장 접속을 확정하지 않습니다.

시공 표지 FOR APPROVAL과 빈 APPROVED 상태를 승인 시공·현재 실물 배선 완료로 해석하지 않습니다.

- P&ID의 LT-01은 LD-01 사일로 옆에 있습니다. OEM FG170/PDF171은 아날로그 LT 채널 대신 LOW LEVEL LD-01 접점 회로를 표시합니다.
- 시공 PDF60 행10_13의 =DUS+LD01-LT01A는 LD-01/DUS2TB1에서 LD-01/LT-01로 이어집니다. DC·CVV·2C·1.0·SPARE0이며 상위 행10_1은 LT01|68FC1|PB14를 함께 적습니다. 도면의 개별 접점 선로 근거이며 현재 아날로그 레벨 백분율을 뜻하지 않습니다.

| 시공 PDF·행 | 원문 케이블 | FROM | TO | 전류형식·선종·코어·굵기 | 검토 |
| --- | --- | --- | --- | --- | --- |
| 60 / 10_13 | =DUS+LD01-LT01A | LD-01 / DUS2TB1 | LD-01 / LT-01 | DC / CVV / 2C / 1.0 | 원본PDF60 행10_13 시각대조; 개별 저레벨 접점 선로. 현재실물 동일성/극성 미확인. |
| 60 / 10_1 | =DUS+LD01-DUS2TB1A | CR | LD-01 / DUS2TB1 · LT01\|68FC1\|PB14 | DC / CVV / 16G / 1.0 | 공유간선: LT01전용채널수 또는68FC1↔170FC1현재대응근거로사용하지않음. |
