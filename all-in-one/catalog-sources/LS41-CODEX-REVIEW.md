# LS41 · 현재 보존 원본 검토

## 1. 설비·자료 기준

LS41(밸브 위치 리미트 스위치)는 실제 대장에서 하위 구성품으로 분류합니다. 담당 부모는 MV06입니다.

개방/폐쇄 위치 센서. 번호·방향·단자·PLC 입력을 상위 장치와 대조한다.

OEM FG33/PDF34의 LS-41 원문 기능은 VALVE CLOSING(밸브 닫힘)입니다. 퓨즈를 거친24V 경로는 X1:65/66에서 E7.0 입력으로 이어집니다.

LS41는 MV06의 끝위치 구성품입니다. 인용한 원시 입력은 구성품 근거로 다루지만 부모 액추에이터 출력·PID·알람을 새 독립 기능으로 복제하지 않습니다. P&ID/시공 LS34/35와 OEM/백업 LS40/41의 번호 상충은 유지합니다.

Dots 원초안은 abcf31c/v1.12.0 당시 연구 자료이며 원문 바이트를 보존했습니다. 아래는 현재 원본과 독립 대조한 검토본입니다.

## 4. 전기 전달 경로

선택한 OEM 원본 위치는 FG30/PDF31, FG31/PDF32, FG32/PDF33, FG33/PDF34입니다. 도면 FG와 PDF 페이지를 별도 필드로 유지합니다.

P&ID에서 이 고유 ID의 독립된 정확한 태그는 확인하지 못했습니다. 대장 pid 표시는 전용 I/O·회로 근거가 아닙니다.
