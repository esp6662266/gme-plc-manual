CLIENT-CL10(Rotex screen)는 실제 대장에서 외부 연동 설비으로 분류합니다. 별도 부모 ID는 배정되어 있지 않습니다.

PLC 외부 모터/설비 채널 10. 원격 신호와 실제 외부 제어반 상태를 대조한다.

외부 인터페이스 범위입니다. 명령·피드백·상태 원본 참조만으로 고객 모터의 배선·내부 인터록·현재 실물 동일성을 확정하지 않습니다.

## 3. 제어 구조

외부 인터페이스 범위입니다. 명령·피드백·상태 원본 참조만으로 고객 모터의 배선·내부 인터록·현재 실물 동일성을 확정하지 않습니다.

CLIENT-CL10의 직접 제어 명세 규칙은 0개입니다. 고객 인터페이스 또는 운전시간 참조를 고객 모터 내부 기동·정지·안전 순서로 확대하지 않습니다.

- 대장 연결 네트워크 419, 1011은 연관 범위입니다. 현재 소유와 실제 동작은 원본 핀·외부 계약·현장 자료로 별도 확인합니다.

## 4. 전기 전달 경로

선택한 OEM 원본 위치는 FG89/PDF90, FG93/PDF94입니다. 도면 FG와 PDF 페이지를 별도 필드로 유지합니다.

P&ID에서 이 고유 ID의 독립된 정확한 태그는 확인하지 못했습니다. 대장 pid 표시는 전용 I/O·회로 근거가 아닙니다.

- OEM 공통 페이지에는 고장 입력도 표시되지만 현재 대장에는 같은 이름의 고장 심볼이 이 항목에 배정되어 있지 않습니다. 현재 사용과 별칭은 추가 원본 대조 대상입니다.
- rotex screen run %i13.4와 OEM 인터페이스 단자 X1:302/303를 비교합니다. 고객 제어반 끝점 및 현재 접속은 별도 확인입니다.

| 원문 신호 | 백업 주소 | OEM 원문 끝점 | 현재 고객/현장 경계 |
| --- | --- | --- | --- |
| rotex screen run | %i13.4 | X1:302/303 | 인터페이스 단자 근거; 고객 제어반 내부/현재 배선 미확정 |

## 5. 알람·복구

대장의 FAULT 원시 행은 외부에서 받은 상태 신호입니다. 같은 이름의 전용 GME 알람 Set/Reset이 식별되지 않은 경우 고객 내부 고장 원인·지연·복구 순서를 새로 만들지 않습니다.

외부 인터페이스 범위입니다. 명령·피드백·상태 원본 참조만으로 고객 모터의 배선·내부 인터록·현재 실물 동일성을 확정하지 않습니다.

## 6. 증상별 관찰

CLIENT-CL10의 원인은 아래 관찰을 실제로 수집한 뒤 원본과 비교합니다. 빈 관찰 양식을 현재 값이나 복구 완료 증거로 채우지 않습니다.

- Rotex screen 인터페이스의 실제 값·시각·주소(rotex screen run %i13.4)와 OEM 단자 및 고객 제어반 끝점의 비교
- 고객 인터페이스·운전시간 원본 참조를 대조하되 고객 안전·기동 내부 회로를 추정하지 않음
