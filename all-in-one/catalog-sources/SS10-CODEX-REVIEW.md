# SS10 · 현재 보존 원본 검토

## 1. 설비·자료 기준

SS10(이송 장치 감시 스위치)는 실제 대장에서 센서·계측 구성품으로 분류합니다. 담당 부모는 MC04입니다.

트립와이어·회전 또는 토크 감시의 실제 장치 종류와 접점 방향을 확인한다.

MC04_torque Monitor 선언과 부모 Inputs.MC04 torque를 구분합니다. 같은 이름의 원시 LAD 핀은 찾지 못했으며 부모 토크 고장 로직은 관련 근거입니다. 예비·OFF 표기로 현재 설치·사용·보호 상태를 확정하지 않습니다.

Dots 원초안은 abcf31c/v1.12.0 당시 연구 자료이며 원문 바이트를 보존했습니다. 아래는 현재 원본과 독립 대조한 검토본입니다.

## 4. 전기 전달 경로

선택한 OEM 원본 위치는 FG24/PDF25, FG25/PDF26입니다. 도면 FG와 PDF 페이지를 별도 필드로 유지합니다.

시공 PDF 태그 등장 페이지 3, 5, 34, 59는 실제 조사 범위입니다. 등장만으로 케이블 끝점·부품 소유·현장 접속을 확정하지 않습니다.

시공 표지 FOR APPROVAL과 빈 APPROVED 상태를 승인 시공·현재 실물 배선 완료로 해석하지 않습니다.

- OEM FG25/PDF26의 SPARE 점선 박스에는 SS-10 토크 접점, 퓨즈 단자 X1:54, 반환 단자 X1:55 및 E6.5가 있습니다. 일반 모터 명령 경로는 박스 밖입니다.
- 시공 PDF59 행9_7의 =EXI+MC04-SS10A는 MC-05/EXI1TB2에서 MC-04/SS-10으로 이어지며 DC·CVV·2C·1.0·SPARE0입니다. 상위 행9_3의 MC05 EXI1TB2 SS10/11은 공통 접속함 표기이며 소유자를 MC05로 바꾸는 근거가 아닙니다.
