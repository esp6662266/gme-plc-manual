## 4. 전기 전달 경로

선택한 OEM 원본 위치는 FG90/PDF91, FG94/PDF95입니다. 도면 FG와 PDF 페이지를 별도 필드로 유지합니다.

P&ID에서 이 고유 ID의 독립된 정확한 태그는 확인하지 못했습니다. 대장 pid 표시는 전용 I/O·회로 근거가 아닙니다.

- 고장 심볼 belt coveyor d fault I16.2의 원문 오기를 유지합니다. OEM FG90은 BELT CONVEYOR D RUN E13.7을 표시하지만 현재 대장에 같은 이름의 운전 행은 없습니다. 없는 행을 만들지 않습니다.
- belt coveyor d fault %i16.2와 OEM 인터페이스 단자 X1:346/347를 비교합니다. 고객 제어반 끝점 및 현재 접속은 별도 확인입니다.
