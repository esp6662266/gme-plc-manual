  1. 최초 알람과 센서/전용반 상태·모드·운전 응답·현재 버전을 같은 시각 기준으로 기록합니다.

  3. Set 앞 조건과 시간의 원본 선언, 연산의 ENO·다른 쓰기·현재 호출을 대조합니다. 제목이나 숫자를 현재 보호값으로 확정하지 않습니다.
  4. Reset 접점·원인 해소·래치 변화·새 기동 허가·출력·실제 응답을 각각 기록합니다. Low_Aspiration·PSL·전용반의 서로 다른 리셋 구성을 비교합니다.
