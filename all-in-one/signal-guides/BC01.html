BC01 · 신호 전달·복수 쓰기 분석

원본 XML 핀과 식별 자료의 Global/Local 범위를 대조한 정적 작업지입니다. 읽기·쓰기 위치는 현재 호출·실행 순서·정상 극성·실제 값을 확정하지 않습니다. 이름만 같은 로컬 변수는 블록별로 구분합니다.
전기 회로 추적시공 케이블 경로진단·수리 작업지전체 신호 분석 목록복수 쓰기직접 전달신호별 원본 위치
원본 호출1612는 Simulation(1),1613의 HMI Inputs는 NOT Simulation(1)과 앞 호출 ENO 경로를 사용합니다. 백업 심볼은 %M180.0입니다. ENO 해석·현재 모드·전체 실행은 확인 전이며 두 블록이 동시에 쓰는 것으로 단정하지 않습니다. 백업 Simulation 블록의 정적 참조이며 새 시뮬레이터 실행·시험은 하지 않았습니다.

6. 수리·개선 확인 기록

  1. 현장 입력·처리된 Inputs·요청 Flag·실제 출력·응답·알람을 별도로 기록합니다.
  2. 동일 신호의 모든 쓰기 Part와 main 허가·호출 경로를 대조합니다.
  3. 리셋·새 운전 요청·자동 시퀀스·전원 재시작의 값 유지 여부를 현재 PLC/TIA에서 확인합니다.
  4. 원본 이름·주소·범위와 관찰 사실을 기록한 뒤 변경 후보를 검토합니다.
