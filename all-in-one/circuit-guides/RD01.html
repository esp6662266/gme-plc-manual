2. 기동 명령

A0.1 ↔ 백업 %Q0.1 / start rd01 · FG21 · PDF 22

  1. A0.1 (FG136/1)
  2. XS:3 → 20QS1 보조접점 → XS:4
  3. 20QM1 보조접점
  4. 21KA1 코일 A1→A2 / 0Vdc10.6

전달·사용 위치: FG20: 20AS1 단자10(+24V) → 21KA1 접점1→9 → 단자13(DI1). 원본1936의 요청·Start RD01과1787의5초 감시를 연결합니다.

진단 판단: PLC 출력, 21KA1 코일·접점과 DI1을 구간별로 비교합니다. 냉각팬 응답·풍량 설정·R2 게이트 조건에 의한 PLC 요청 해제는 진단 작업지에서 확인합니다.

원본 심볼 직접 참조: 1787 / allarms 1 / ORef 328 · 1936 / motors 1 / ORef 251 · 1938 / motors 1 / ORef 270

3. 운전 응답

E0.2 ↔ 백업 %I0.2 / rd01_fbk · FG20 · PDF 21

  1. +24Vdc10.7 → 20AS1 단자22
  2. 단자24 → E0.2
  3. PLC 입력 참조 FG116/3

전달·사용 위치: 원본1787·1936은 내부 Inputs.RD01 run을 사용합니다. 물리 입력→내부 DB의 전체 전달은 미확정입니다.

진단 판단: 도면의 릴레이 전원·신호 측과 PLC 입력을 구간별로 비교합니다. 출력 기능·접점 극성·내부 반전은 현재 설정을 확인합니다.

원본 심볼 직접 참조: 1019 / time work motor / ORef 1180 · 1931 / motors 1 / ORef 23

4. 인버터 이상

E0.3 ↔ 백업 %I0.3 / rd01_all_inv · FG20 · PDF 21

  1. +24Vdc10.7 → 20AS1 단자25
  2. 단자27 → E0.3
  3. PLC 입력 참조 FG116/4

전달·사용 위치: 원본1787의 RD01_INV 래치와1936의 요청 해제를 추적합니다.

진단 판단: 백업 이름과 도면 ALARM 표시를 대조합니다. 정상 입력값을 가정하지 않고 실제 접점·입력·래치 상태를 각각 기록합니다.

원본 심볼 직접 참조: 복원 LAD에서 이 이름의 직접 참조는 찾지 못했습니다. 내부 Inputs 등의 별도 전달·미해석 참조·현재 프로그램은 확인 전입니다.

5. 속도 설정

±PAW290 ↔ 백업 %QW290 / rd01_sp_speed · FG20 · PDF 21

  1. +PAW290 → 20AS1 단자2(AI1+)
  2. -PAW290 → 단자3(AGND)
  3. 아날로그 출력 참조 FG112/1

전달·사용 위치: 드럼 속도 설정. 전체 아날로그 변환·PID·다른 쓰기를 확인합니다.

진단 판단: 도면의 4–20mA 표기와 실제 입력 모드·스케일을 대조합니다. 요청 설정, 원시 출력, 전기 신호와 인버터 표시를 분리합니다.

원본 심볼 직접 참조: 1684 / analog output conversion / ORef 437

6. 전류 전달

±PEW332 ↔ 백업 %IW332 / rd01_current · FG20 · PDF 21

  1. 20AS1 단자8(AO2) → +PEW332
  2. 단자9(AGND) → -PEW332
  3. 아날로그 입력 참조 FG109/4

전달·사용 위치: 원본1071 Part144: RD01_Current → Inputs.RD01_ABSORBPTION.

진단 판단: 전류 환산·단위·AO2의 실제 기능과 전체 값 전달을 확인합니다. 도면의 기본 기능만으로 현재 파라미터를 확정하지 않습니다.

원본 심볼 직접 참조: 1071 / hmi inputs / ORef 148 · 1771 / analog input conversion / ORef 1504
