원본 백업의 정적 알람·타이머·리셋 근거입니다. 현재값·실물 동일성·현재 CPU/TIA 실행·복구 완료는 확인 전입니다. 원본 설정은 권장 보호값이나 실제 경과시간을 뜻하지 않습니다. PLC 변경0건, 시뮬레이터 작성·시험 중지.
알람·복구 전체 비교수리 판단전기 회로신호 전달·다른 쓰기수리 관찰 기록

4. 요청 해제와 재기동 경계

기존 수리 판단 대장에 직접 배정된 요청RCoil은 없습니다. 자동 허가·단계·출력·위치 기억의 조건은 수리 판단/제어 명세와 함께 확인하며 요청 해제 경로 전체가 없다는 뜻으로 해석하지 않습니다.

  1. 최초 원인 입력과 현장 상태·최초 알람의 시각을 기록합니다.
  2. 원인 해소 근거와 리셋 요청·래치 변화·현재 호출·다른 쓰기를 구분합니다.
  3. 래치 해제 이후 새 요청·모드·최종 출력 허가와 구동기 자체 복구 조건을 대조합니다.
  4. 승인된 재기동의 실제 출력·응답·연동 상태를 기록합니다. 빈 관찰값은 미확인으로 남깁니다.
