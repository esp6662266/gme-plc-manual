보존 XML·선언과 burner-interface.json을 대조한 정적 문서입니다. 외부010-390 TYPE BP N300의 화염·점화·퍼지·가스 차단 내부 순서, 현재 CPU·현장 복구는 확인 전입니다.

LDU와 외부 리셋

LAD1854 / 0171: ON219·raw LOCKOUT221·!APP223→S117 LDU DB3X7.4. ON·RESET225·LDU227→m491/APP Set. APP 6초(T26), m491 2초(T27)와 Q6.7, T27 이후 LDU Reset와 2초(T28), T28 이후 m491 Reset을 구분합니다. 시작 가지에 raw LOCKOUT 정상화 접점은 없습니다. PLC 래치 Reset과 외부 리셋 수용·실제 화염/안전 복구는 별도입니다.

최소위치 이름과 압력 도면

LAD1855 / 0172: ON·Start요청·PBox M50.0·(!FC GAS OR !FC AIR)→SERVOMOTOR_MIN_POS_ALL DB3X7.0 Set; ON·RESET·자기fault→Reset. DB13X17.3/.5의 닫힘 이름과 FG97의 최소압력 S3 명칭 상충을 유지합니다. 현재 서보위치 보호나 정상극성은 확인 전입니다.

시작실패와 운전시간

LAD1869 / 0185는 STARTFAULT DB3X6.7의 RESET·자기fault→Reset만 확보했습니다. Set 원천/기동 타임아웃은 미확보입니다. 1859의 W5/1분 계수와 1861 OFF·W5≥1440 ProgrammedStop / ≥1320 TIME22H, 1860 HMI 정지계수/Resetcount는 서로 다릅니다. OFF를 False 상수로 바꾸거나 계수 Reset을 외부 LOCKOUT 해제로 설명하지 않습니다.

별도 비율한계와 아날로그

1874 / 0189: ON·(Sign_lim_min OR MAX)→T90 20초→Sechio_Limits DB3X7.2 Set. Reset은 ON·RESET·자기fault·!min·!max를 요구합니다. 1752~1755의 가스/공기/질량유량 OFR는 별도 환산 출력입니다. 현재 단위·곡선·튜닝·적정 연소비는 미확정입니다.

출력·세척과 외부 안전 경계

1863 / 0179 T122의 원문4초와 FG99/143 인쇄3초를 보존합니다. 1868 / 0184에는 동일 MV03 Close의 정·부정 직렬 가지, State77, 4분/1초/30초와 다중쓰기가 있습니다. 이러한 GME 내부 명령을 외부 화염 판정·퍼지·점화 안전 완료로 대체하지 않습니다.
