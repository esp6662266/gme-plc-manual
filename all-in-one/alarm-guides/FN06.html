FN06 · 알람 발생·리셋·재기동 근거

원본 백업의 정적 알람·타이머·리셋 근거입니다. 현재값·실물 동일성·현재 CPU/TIA 실행·복구 완료는 확인 전입니다. 원본 설정은 권장 보호값이나 실제 경과시간을 뜻하지 않습니다. PLC 변경0건, 시뮬레이터 작성·시험 중지.
알람·복구 전체 비교수리 판단전기 회로신호 전달·다른 쓰기수리 관찰 기록

2초 감시의 원본 래치 이름은 Allarm.MBVA01_FAULT입니다. FN06 별칭 관계는 확인 전이며 RD01 응답 상실에 의한 요청 해제와 구분합니다.

1. 발생·리셋 조건 비교

Set은 래치 발생 조건, Reset은 래치 해제 조건입니다. 아래 식은 기존 원본 분석의 정적 요약이며 1/ON을 현재 상수로 보지 않습니다. 원인 해소·리셋 명령·래치 해제·새 운전 요청·실제 응답을 각각 확인합니다.
