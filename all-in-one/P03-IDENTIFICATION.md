## 식별과 제공 자료

배치도 명칭은 웨잉호퍼1이다. 백업의 WEIGHTING HOPPER 2FAULT는 호퍼2 외부 고장 입력이다. 이름과 번호가 달라 CLIENT-CL17 또는 BWF01을 P03으로 확정하지 않는다. 대장 부모/자식 연결도 새로 만들지 않는다.

## 후보 입력·HMI 경계

0234 LAD424/NID17, 0599 RID38 UID341/343 Global Input AO132=SAD Input/SAM None, I16.4. 0601 RID39 UID342/345는 Allarm.motor_client_17_fault AO129 쓰기다. 원시 입력과 알람 기억을 구분한다. I16.5/CLIENT-CL18과 BWF01/02 입력·처리DB·HMI는 별도 경로이며 P03의 계량값/단위/로드셀 채널로 배정하지 않는다.

## 외부 요청과 내부 제어

0239/0240 LAD1932/1933는 BWF01/02의 별도 인터페이스다. ON 아래 자기 Fault, ControlFault, SET_PERC=Int0, NOT 처리 BWF OK, NOT 처리 BC01 run, Local Disable_Load_RD01의6 OR→자기 M_BWF 요청 Reset. 별도 ON AND M_BWF→Consent Start Q6.2/Q6.3 Coil. 허가 출력과 실제 Run/계량 내부 순서가 다르다. 다른 쓰기·호출순서·외부반 기동순서 미확보.

## 원본·시공 전달 경계

OEM FG94/PDF95: +24Vdc10.7→X1:350(2A F)→외부 고장 접점→351→E16.4. FG132/PDF133: CPU515/MOD12 단자5, WEIGHTING HOPPER 2FAULT. 외부반 접점·단자·케이블·호퍼 명판은 미확보다. 시공은 FOR APPROVAL/첫 초안24.11.11이며 PDF21/51 BC01 M02 경로를 P03 계량기 회로로 복제하지 않는다. PDF50 길이17은 예시이고 PDF51 1_1 길이22 표기와 구분한다.

## 후보 알람과 Reset

LAD424: ON355→Fault357→Wire358→S334. Reset은 ON355→NOT Fault359→RESET_ALLARM361→Wire362→R339. 6개의 Gate Part와11Wire이며 타이머/Ready/Run/기동 Coil이 없다. 이 선택 네트워크의 범위만 확인한 것이며 전체 외부 제어기의 부재를 뜻하지 않는다. 기억 해제와 외부 고장 해소·허가 회복·계량 정확도 복구는 별도다.

## 실물 확인과 필요한 자료

호퍼1/2 번호·명판·위치 사진, 로드셀/인디케이터 모델, 전용반·CPU·통신/단자도, 투입·배출 경로가 필요하다. 후보 문서 확인은 실물 동일성·TIA 컴파일·현재 CPU·현장 복구 확인이 아니다. 제조사/보호값/기동순서를 임의 채우지 않는다.
