설비와 자료의 소유 경계

  • `registers/equipment.json` VR06행은 motor/FG64, parent 빈값, 별칭 빈 배열이다. P&ID에서 LD01와 붙어 있더라도 catalog parent를 LD01로 바꾸거나 M32/M33·LT01를 VR06 소유로 배정하지 않는다.
  • `PID_1684n002I.pdf` p1을 실제 렌더했다. LD-01 하부 M32 출구 아래 VR-06/M40이 있고, FN-05/M41→ER-01 공기 경로가 그 하부 유로에 접속한다. M40은 0.25kW/440V, M32/M33은 각각0.18kW/440V다. 이웃 기기 용량을 VR06에 복제하지 않는다.
  • `Electrical_Rev2.pdf` FG64/PDF65 제목은 ROTARY VALVE VR-06, M40은0.25kW/0.76A다. 64QM1→64KM1→64QS1→M40 직접기동 경로다. 이 직접 경로에서 인버터 속도지령·아날로그 전류/PID·엔코더는 비해당이다. 현장에 추가 장치가 없다는 뜻은 아니다.
  • VR06이 ER01 출력 명령을 읽고 LD01 요청에 영향을 주는 PLC 의존성과 실제 물질·공기 전달 관계는 구별한다. ER01 내부 온도·안전제어, FN05 실제 송풍, LD01 실제 투입량은 본 문서가 확인한 VR06 신호만으로 보증되지 않는다.
  • P&ID 도번1684n002는 원 작성일06/04/2011, 판I 변경일15/01/2013이다. 개정E(12/11/2011)에 M15/17/40/41 모터출력 변경이 기재되어 있다. 현행 명판 증거가 아니다.
  • 전기 검토 시트 FG64/121/140/254는 하단 기본 날짜27.05.2024가 보인다. 파일명 Rev2만으로 모든 시트에 같은 Rev2 날짜를 부여하지 않는다. 시공 PDF36/51은24.11.11 first draft design, CHECKED/APPROVED 공란이다. 승인 준공도·실측 길이로 승격하지 않는다.
