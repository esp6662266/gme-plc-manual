설비와 소유 경계

  • equipment.json은 SC10을 `BF01 분진 스크루`, FG57, parent 빈값으로 기록한다. P&ID `PID_1684n002I.pdf` p1 실제 렌더에서 BF-01 하부 SC-10/M34(3 kW 440 V)와 출구 VR-04/M38(0.55 kW 440 V)을 구분했다. 기계적 관계와 catalog 부모 관계는 별도다.
  • `Electrical_Rev2.pdf` FG57/PDF58의 M34 SC-10은 `FILTER DUST SCREW`, 3 kW/5.8 A, 440 V 60 Hz 삼상 전력 경로다. 57QM1–57KM1–57QS1의 직접기동 회로이며, 해당 직접 회로에 전용 VFD·속도 설정·PID·엔코더·아날로그 전류 경로는 식별되지 않았다. 이 회로 설명에서 해당 기능은 비해당이며, 현장 장비의 부재까지 단정하지 않는다.
  • VR04 처리 Run은 SC10 요청 Reset 조건에 참여한다. VR04 자체 출력·모터·고장·보호값을 SC10에 병합하지 않는다. BF01 본체·DP01·세척 EV군·공기계통도 SC10 전용 소유가 아니다.
  • SC10 처리응답은 BF01 세척허가와 FN04 공유 예고장에 기여한다. 이것은 SC10이 BF01의 모든 세척 기능 또는 FN04의 90분 타이머를 소유한다는 뜻이 아니다.
  • 원본의 문서 시점: 전기 FG57/121/140/253 기본 날짜27.05.2024, 해당 검토 시트에 개별 Rev2 표시는 보이지 않았다. 파일명 Rev2를 모든 시트의 개정으로 확대하지 않는다.
