2. 설비·신호 경계

직접 요청·출력·PLC 태그를 부여하지 않았습니다. 본체 또는 전용 제어기의 명판·반 명칭·전용 자료·접점/통신 연동 근거가 필요합니다.

3. 공통 단계의 해당 신호 쓰기

직접 배정한 공통 자동 단계는 없습니다. 전용 제어기와 GME의 연동 경계를 먼저 식별합니다.

4. 최종 출력의 허가·억제 조건

최종 출력을 식별하기 전입니다. 해당 설비의 전용 자료와 현재 I/O를 확인합니다.

5. 현장 출력·응답 전달

현재 회로와 연동을 확인하기 전입니다. 다른 설비의 단자·출력·센서를 복사하지 않습니다.

6. 감시·연관 허가·복구의 관련 쓰기

전용 알람 조건을 식별하기 전입니다. 현재 제어기의 알람·리셋 근거를 확보합니다.

  1. 본체·전용 제어기의 자료와 현재 상태를 확인하고 관찰·조치·미확인 항목을 기록합니다.
