P07 · PV-02 수리 판단·공통 영향 작업지

원본 근거를 연결한 수리 판단 검토본입니다. 현재값·설치 동일성·현재 CPU·TIA 동작·현장 수리 완료는 확인 전입니다. 시뮬레이터 작성·시험 중지.

태그명 일치 / 실물 확인 전 · 참고 PLC 자료: PV02

MC04 응답·배출 자동 허가·두 게이트 명령과EV 출력을 구분합니다. LS25/26 행 위치와 현재 센서 극성·배선은 확인 전입니다.

수리 판단 전체 목록실물 대응·점검이 설비의 공통 제어증상별 상세 수리전기 회로 추적신호 전달·복수 쓰기알람 발생·리셋·재기동 근거HMI 태그·설정·표시 전달 확인레시피·설정값·초기화와 다른 쓰기

1. 관찰 결과별 판단 순서

관찰 분기먼저 기록원본 비교다음 판단
운전 요청이 없거나 곧 해제됨현재 모드·공정 종류·Auto_ON1·카운터와 해당 요청의 변화를 같은 시각 기준으로 기록합니다.아래 공통 단계의 관련 쓰기와 해당 요청의 모든 Global 쓰기 위치를 비교합니다. 원본 단계 Set이 현재 호출됐는지는 별도 확인합니다.상위 요청 미발생, 정상 정지 단계, 고장에 의한 요청 Reset을 구분합니다. 기동 명령을 추가하기 전 요청을 지운 주체를 확인합니다.
관련 근거·확인
요청은 있지만 최종 출력이 없음아래 최종 출력의 전체 조건과 현재 피연산자·모드를 기록합니다. 미해석 조건은 임의로0/1로 채우지 않습니다.공통 ON·비상 모듈·모드 허가와 장치별 출력 조건을 대조합니다. Set 요청은 실제 Q 출력 또는 위치 도달의 증거가 아닙니다.억제 접점·반대 방향 출력·끝단·상하류 응답 중 실제로 조건이 다른 지점을 찾습니다. 현재 호출·다른 출력 쓰기도 함께 확인합니다.
관련 근거·확인
출력은 있지만 현장 응답이 없음최종 PLC 출력, 릴레이·구동기 입력, 실제 장치 상태, 원시 센서와 처리된 응답을 구간별로 기록합니다.회로 작업지의 단자·직렬 허가·전원·구동기와 아래 응답 원본 참조를 비교합니다. 내부 기억만으로 물리 동작을 판단하지 않습니다.출력 전달 구간과 센서 전달 구간을 각각 확인합니다. 회로·원시 입력·Inputs·기억 중 어디서 차이가 시작됐는지 남깁니다.
관련 근거·확인
운전 중 정지하거나 연관 설비와 함께 정지함최초 알람·상하류 응답 변화·카운터·요청 Reset·출력 OFF의 시각을 기록합니다.종류5 공통 정지 및 아래 장치 감시의 Set/Reset·시간 설정을 함께 비교합니다. 자동 단계 수치를 실제 초로 확정하지 않습니다.최초 원인과 후속 정지를 구분하고 관련 설비의 상태도 남깁니다. 최초 발생 기록 없이 후속 알람만으로 원인을 확정하지 않습니다.
관련 근거·확인
리셋 후 재기동되지 않거나 같은 알람이 반복됨원인 입력·래치·새 요청·출력·응답과 리셋 요청/출력을 각각 기록합니다.장치별 RCoil과 공통930/931·비상1824·startup404/405의 기억을 구분합니다. 공통 리셋 출력은 물리 이상 해소의 증거가 아닙니다.원인 해소·래치 해제·허가 확인·승인된 재기동·연동 영향 확인을 분리해 기록합니다. 현재 PLC·실물 증거 전에는 수리 완료로 표시하지 않습니다.
