알람·설정값 추적

설비 이름으로 일치한 알람 전용 네트워크가 없다. 상위 설비 고장 및 일반 진단 블록의 참조를 확인한다.

관련 검색 코드의 시간 상수 후보: 직접 상수 없음 / 설정 DB 및 타이머 인스턴스 확인. 여러 설비를 포함한 공유 네트워크의 상수도 포함된다. 실제 적용 대상·접점 경로·설정 DB 값은 원본에서 확정한다.

운전 확인과 고장 진단 절차

아래는 설비 유형에 맞춘 점검 절차안이다. 원본에서 확정한 제어 논리와 현장 절차를 대조해 승인용 문서로 발전시킨다.

  1. 논리 명칭 확인 — 이 항목이 물리 계기인지 PLC 내부 공학값/루프 이름인지 확인한다.
  2. 데이터 추적 — 원시 입력→선택/환산→제어 루프→HMI 값을 네트워크와 DB 주소로 연결한다.

시뮬레이터 모델과 시험 설계

시뮬레이터는 운전 요청, 허가, 출력, 지연 응답, 고장, Reset, 초기값을 각각 저장한다. 물리 입력과 내부/HMI 상태를 분리하며, 임의로 넣은 지연·관성·공정 계수는 교육용 가정으로 표시한다. 아래 시험은 아직 실행하지 않았다.
