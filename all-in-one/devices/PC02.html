설비 제어 명세: 입출력·동작 조건·순서·이상 처리·근거

계측 · 소프트웨어 명칭·물리 태그 확인
백업의 PC02 관련 데이터 명칭. PSH02와 물리 센서 동일성은 별도 검증한다.

공정/기능 연관 장치: PSH02, MV06. 배관 또는 기능 관계이며 모든 장치 간 자동 인터록을 뜻하지 않는다.

도면·식별과 현재 확인 범위

PLC·전기 자료 기준 항목. 직접 전기 회로 식별 근거 없음

관련 물리 I/O 0개, 내부 심볼 2개, HMI 설정 0개, 관련 래더 1개. 목록은 태그 참조를 연결한 자료이며 공유 신호·상위/하위 설비 참조도 포함한다. 채널의 독점 소유나 독립 설비 전용 블록 수를 뜻하지 않는다.

구분현재 백업 주소원본 심볼자료형원본 설명 / 과거 주소색인 근거
내부%M40.4pc02 closebool_7ev / 65

위 주소는 백업 심볼의 Address 값이다. 옛 I/O 주소가 설명에 남아 있어 설명 문자열을 현재 주소로 사용하지 않는다. 단자·퓨즈·릴레이·모듈 배선 확정은 아래 전기 원문에서 별도로 수행한다.

HMI 설정 주소와 표시 의미

직접 태그 이름으로 일치하는 HMI 설정은 없다. 가공·통합 상태 또는 상위 설비 화면 참조를 별도 확인한다.

HMI 주소는 dde.cfg 설정값이며 PLC 물리 I/Q와 다를 수 있다. 표시색·입력값·알람 팝업은 화면 스크립트 및 온라인 값으로 추가 검증한다.

알람·설정값 추적

설비 이름으로 일치한 알람 전용 네트워크가 없다. 상위 설비 고장 및 일반 진단 블록의 참조를 확인한다.

관련 검색 코드의 시간 상수 후보: 직접 상수 없음 / 설정 DB 및 타이머 인스턴스 확인. 여러 설비를 포함한 공유 네트워크의 상수도 포함된다. 실제 적용 대상·접점 경로·설정 DB 값은 원본에서 확정한다.

운전 확인과 고장 진단 절차

아래는 설비 유형에 맞춘 점검 절차안이다. 원본에서 확정한 제어 논리와 현장 절차를 대조해 승인용 문서로 발전시킨다.

  1. 논리 명칭 확인 — 이 항목이 물리 계기인지 PLC 내부 공학값/루프 이름인지 확인한다.
  2. 데이터 추적 — 원시 입력→선택/환산→제어 루프→HMI 값을 네트워크와 DB 주소로 연결한다.

시뮬레이터 모델과 시험 설계

시뮬레이터는 운전 요청, 허가, 출력, 지연 응답, 고장, Reset, 초기값을 각각 저장한다. 물리 입력과 내부/HMI 상태를 분리하며, 임의로 넣은 지연·관성·공정 계수는 교육용 가정으로 표시한다. 아래 시험은 아직 실행하지 않았다.
