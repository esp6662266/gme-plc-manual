# GME PV01 첫 매뉴얼 패키지

작성일: 2026-10-07 · 개정 0.1

`PV01-manual.html`을 브라우저에서 열면 목차, 배선 그림, 표와 원본 자료 링크를 읽을 수 있습니다. `PV01-manual.md`는 수정 가능한 원문입니다. 폴더 전체를 유지해야 그림과 도면 링크가 작동합니다. 압축 파일을 받은 경우 먼저 압축을 해제하세요.

## 포함 내용

- 상세 매뉴얼 12개 절 및 부록 2개.
- PLC 입출력 8개와 HMI 설정 주소 10개 대응표.
- 내부 요청·모드·타이머 태그 28개 목록.
- 추가 검증 항목 14개, 시뮬레이터 시험 시나리오 18개.
- 선택한 PLC 색인 근거 72개 문서와 네트워크 위치 29개.
- 업로드된 P&ID·전기도면의 동일한 사본, HMI 이미지, 출처·해시 기록.

## 검토 상태

태그와 주소를 원본 분석 자료 및 HMI 설정에 대조했습니다. 원본 자료를 복사한 파일의 해시가 일치합니다. HTML 목차와 표가 브라우저에서 표시되는 것도 확인했습니다.

현재 PLC와 백업의 일치, 래더 접점 연결, 센서 실사용, 실제 동작은 검증 대기입니다. 시험표의 모든 항목은 실행 전이며 결과는 미기록입니다. 본 패키지는 시뮬레이터 구현 또는 PLC 제어 변경을 포함하지 않습니다.

PV01 순서를 확정하려면 관련 TIA 래더와 DB 선언부·교차 참조가 필요합니다. 자세한 검토 위치와 완료 조건은 매뉴얼의 5절과 11절에 있습니다.

`build-review.py`는 이 작업 환경의 원본 경로를 이용한 생성 스크립트이며 다른 PC에서 실행하려면 자료 경로를 수정해야 합니다. 읽기와 검토에는 스크립트 실행이 필요하지 않습니다.
