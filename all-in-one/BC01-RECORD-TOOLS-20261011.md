# BC01 자료·기록 도구 — v1.2.0 · 2026-10-11

BC01(P01)만 대상으로 네 기능의 구현과 로컬 검증을 완료했습니다. 현재 게시 상태는 GitHub 루트의 PUBLICATION_STATUS.md와 Netlify의 해당 커밋 배포 결과를 함께 확인합니다.

| 기능 | 사용 방법 | 보존·확인 경계 |
|---|---|---|
| 도면·래더 나란히 | BC01 매뉴얼·도면·수리 화면 상단 버튼 → 전기 경로와 원본 위치 선택 | FG18/PDF19·FG19/PDF20, 원본 Part/Wire 56곳 및 LAD1018 참고. 원시 입력·처리 알람 참고·직접 대응 없음 구분 유지 |
| 백업 가져오기·복원 | 전체 메모 백업 또는 개별 저장 수리 기록 JSON 선택 → 미리보기 → 충돌별 선택 → 저장 | BC01만 추가/기존 유지/값 복원/새 ID 복사. 다른 설비·초안·미지 필드 보존. Web Locks 없는 환경은 미리보기/내보내기만 제공 |
| 점검 전후 비교 | 저장된 두 BC01 수리 기록을 앞·뒤로 직접 선택 | 신호·비교 항목 ID로 값·시각·근거·저장 이름/주소/시간대 비교. 미기록과 0 구분. 자동 고장·복구 판정 없음 |
| 관찰 결과 보고서 | 저장 기록 선택 → 보고서 미리보기 → 인쇄·PDF 또는 전체 JSON | 저장 후 자료만 출력. 다른 탭 변경 시 다시 생성. 알려지지 않은 추가 필드는 전체 JSON에 보존 |

빈 관찰 양식 JSON은 복원 대상이 아닙니다. 저장 화면의 개별 수리 기록 JSON이나 전체 메모·수리 기록 백업을 사용합니다. 기존 자료요청용 인쇄 작업지는 계속 제공하며 이번 관찰 결과 보고서와 목적이 다릅니다.

브라우저 기록은 컴퓨터·브라우저·주소·포트마다 별도입니다. 다른 컴퓨터로 옮길 때 기존 브라우저에서 JSON 백업을 다운로드하고 새 브라우저의 BC01 도구에서 선택 복원합니다. 실제 사용자 기록과 로그인·인증 정보는 코드 저장소·ZIP에 자동 포함되지 않습니다.

검증: 신규 Node 검사(잘못된 입력19종, 원본 위치57곳), 기존 수리 기록23양식/근거 링크3456개, PC1280×900·모바일390×844·기본/큰 글자, 미리보기와 실제 저장/재읽기, 다른 탭 충돌, 저장 중 파일 변경, 저장 실패, 미지 필드/다른 설비/초안 보존, 문자열 이스케이프, 보고서의 변경 감지와 브라우저 PDF를 확인했습니다. 전용8871 시험 주소의 가상 기록만 사용하고 원래 빈 저장 상태로 복원했습니다. 최신 필수14검사와 패키지 CRC·전체 SHA256는 all-in-one-package-manifest.json의 fresh_verification_runs 및 해당 검증 JSON에서 확인합니다.

원본730개와 추가 원본3개, 중지 자산5개는 해시로 보존합니다. 시뮬레이터 작성·수정·실행·행동 시험0, 실제 PLC/현장/보호값 변경0, BC01 밖 확대0, SEJIN 수정·사진/이력 복제0입니다. TIA 컴파일·현재 CPU/실물·ABB 현행 모델/단자/정상 극성·현장 복구는 별도 확인 대기입니다.

다른 컴퓨터의 최신 재개 방법은 저장소 루트 WORKSPACE-HANDOFF.md, 현재 범위는 ACTIVE-WORK.md, 버전명은 VERSION.json을 먼저 읽습니다. 과거 안내의 시뮬레이터 계획은 최신 중지 지침보다 우선하지 않습니다.
